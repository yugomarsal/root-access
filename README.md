### 📖 About The Project

**Root Access** is a browser-based neon cyberpunk terminal quiz game.  
You play as an underground operator trying to breach systems, fix errors, and gain the highest privilege level: **root**.

The game features three progressive difficulty levels, a high score system, sound effects, CRT scanline aesthetics, and a full terminal-inspired interface.

Built entirely with pure HTML, CSS, and JavaScript — no frameworks, no build tools, no dependencies.

---

### ✨ Features

- **Three Difficulty Levels**
  - `ACCESS_GRANTED` (Easy) → 10 questions • Multiple choice (A B C)
  - `BREACH_IN_PROGRESS` (Medium) → 15 questions • Story + Multiple choice (A B C D)
  - `ROOT_ACCESS` (Hard) → 20 questions • Type the exact command

- **High Score System** (saved in browser via localStorage)
- **Sound Effects** (correct / wrong / level complete)
- **Neon CRT Aesthetic** with scanlines and glow effects
- **Fully Responsive** (works on mobile & desktop)
- **Instant Play** — zero install
- **Landing Page** with FAQ and project explanation
- **Social Integration** with X (Twitter)

---

### 🎯 How To Play

1. Open the [Live Demo](https://yugomarsal.github.io/root-access/)
2. Click **START ROOTING**
3. Choose your difficulty level
4. Answer the questions correctly
5. Keep your lives (you only have 3)
6. Aim for the highest score and unlock **Elite Operator** rank
